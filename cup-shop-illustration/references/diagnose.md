# 照片识别卡 · 自检清单 · 失败修法

## 一、照片识别卡（Step 1 填）

用视觉能力直接看原图，不要先跑边缘检测或生成线稿。`prepare` 打印的信息卡可交叉验证方向、亮度、主色。

| # | 字段 | 判读要点 | 示例（示例图左半） |
|---|---|---|---|
| 1 | 品牌名 | 杯身 logo / 文字，取英文名或拼音；读不出就写「杯身原有文字」 | `GridCoffee` |
| 2 | 饮品名 | 标签、小票、用户说明；不确定就省略副标题 | `Americano`（用户补充） |
| 3 | 杯型 | 纸杯 / 塑料杯 / 罐 / 瓶；宽高比；上宽下窄程度 | 外带纸杯，上宽下窄，约 1:1.4 |
| 4 | 顶部结构 | 杯盖厚度、饮用口、吸管、奶盖、奶油、封膜 | 米白色厚杯盖，带一个方形饮用口 |
| 5 | 主色 / 辅色 | 大面积色块；与信息卡 dominant_colors 对照 | 深橄榄绿 + 米白 + 白色 logo |
| 6 | logo 与文字 | 形状、位置、颜色 | 杯身中部白色空心方框，下方白色小字 |
| 7 | 配料 / 装饰 | 咖啡豆、珍珠、水果、饼干碎、分层、冰块 | 无可见配料（不透明杯） |
| 8 | 产地 / 联名 | 用户补充或包装文字 | 云南 · 秋珀庄园（化作 A 字牌与咖啡果枝） |
| 9 | 原图方向 | portrait / landscape / square → 决定画布与拼接 | 单张饮品照多为 portrait |

**三条判读纪律**
1. 用户明确给的信息 > 照片读数 > 常识推断。
2. 读不出的一律不编造；「不透明杯看不见配料」就不要写珍珠。
3. 保留原始造型，重新设计的是建筑功能，不是包装设计。

## 二、九条自检（Step 4 逐条比对）

| # | 检查项 | 合格标准 |
|---|---|---|
| 1 | **一眼认出** | 杯型比例、主色、logo 位置与原图一致，能指认出是哪杯饮料 |
| 2 | 等轴测视角 | 斜上方 45°、俯视 30°，顶部/正面/侧面/地台同时可见，不是平视产品图 |
| 3 | 2D 矢量 | 粗黑均匀描边、纯色平涂、圆润几何；无 3D 渲染 / 塑料高光 / 渐变 / 软阴影 |
| 4 | 建筑化 | 杯盖变屋顶平台、杯身开门窗、有楼梯/遮阳棚/招牌，不是「原杯加贴图」 |
| 5 | 生活气息 | 吉祥物/店员小人在活动，绿植、桌椅、A 字牌等围绕品牌特色展开 |
| 6 | 标题 | 顶部英文主标题清晰无乱码，圆润粗体，距顶 ≥8%，不贴杯盖 |
| 7 | 构图完整 | 建筑、楼梯、人物、地台、标题全部入画，左右/底部留 6%–8% 安全边距 |
| 8 | 背景 | 与品牌协调的明亮纯色，少量平面装饰，不抢主体 |
| 9 | 拼接真实性 | 对比图左侧是**用户上传的真实原图**，等比缩放、无裁切无拉伸；插画完整未裁 |

**三条必查中的三条**：1（认出）、3（2D 矢量）、7（不截断）。这三条任一不合格即重出。

不合格 → 按第三节只改对应一段提示词 → **最多重试一次**。仍不合格，如实交付并列出可调方向，不要伪装成功。

## 三、失败修法表

| 症状 | 原因 | 只改这里 |
|---|---|---|
| 出成写实照片 / 3D 小摆件 | 风格锚点被「micro diorama / 3D」语义带跑 | 提示词第 3 段首行加粗重复 `Bold Outline Isometric Flat Vector Illustration`，追加完整负面词表 |
| 复制了原照片的平视角度 | `input_fidelity` 过高把版式锁死 | 降到 `low`~`medium`，并在第 2 段重复「45° / 30° / 顶面可见」 |
| 换成了别的杯子 / 换了品牌色 | 保真不足 | 升到 `high`，`{{OBSERVATION}}` 写死主色与 logo 位置，加「do not redesign the packaging」 |
| 标题乱码、多出无关文字 | 模型文字渲染不稳 | 主标题缩到 1 个短词、去掉副标题；追加 `NO extra text` |
| 中文招牌变方块 | 中文渲染能力有限 | 主标题保持英文；中文小字牌改用 PIL 后期叠加（见第四节） |
| 地台或楼梯被裁 | 主体画太大 | 第 5 段追加 `leave 10% empty margin at the bottom, show the whole base platform` |
| 元素堆成一团 | 特色元素写太多 | `{{FEATURES}}` 删到 2–3 项，设施列表去掉滑梯/观景台 |
| 画面像照片加了滤镜 | 图生图保真过高 | `input_fidelity` 降到 `low`，第 3 段风格条款前置 |
| 对比图里原图变形 | 用了错误的缩放方式 | 只用 `imgtool.py compose`，它按高度/宽度等比缩放，不拉伸 |
| 右下角有「AI生成」水印 | 平台强制叠加 | `footnote: ""` 先试；仍有用 `trim <图> --bottom 0.06 --mode pad` 后再拼接 |

## 四、中文文字怎么处理（可选）

图像模型写中文容易乱码。**默认所有标题用英文**。若用户明确要中文招牌（如示例图的「云南 秋珀庄园」A 字牌）：

1. 提示词里只要求「画一块空白的木质 A 字牌」，不要求写中文；
2. 出图后用 Pillow 在牌面区域叠中文（系统字体，如 `C:/Windows/Fonts/msyh.ttc`），用 `imgtool.py` 之外的一段小脚本完成；
3. 或者干脆不叠，把产地信息放在英文副标题里（`Yunnan · Giupo Estate`），最稳。

不要为了中文把整张图重出，代价高且不一定变好。

## 五、`input_fidelity` 取值逻辑

| 值 | 效果 | 什么时候用 |
|---|---|---|
| `low` | 模型更放手，构图自由度大 | 画面像照片临摹、视角没转过来时 |
| **`medium`（默认）** | 保住杯型/配色/logo，又允许重新构图 | 绝大多数情况 |
| `high` | 锁得更死，容易连拍摄角度一起保留 | 杯型或品牌色被换掉时 |

与「旅行照片卡片」类技能不同：这里**要保住包装识别特征**，所以默认值是 `medium` 而不是 `low`。

## 六、平台水印与裁切边界（2026-11-08 实测）

**实测结论**：即使 `footnote: ""`，平台仍会在插画右下角强制叠两行白字「AI生成 / WORKBUDDY」。位置约在 `x 0.88–1.0、y 0.945–0.99`，贴着画布边缘。

| 做法 | 结果 |
|---|---|
| `trim --bottom 0.06` | ❌ 会切到地台，破坏第 7 条自检 |
| `cleanwm --mode fill`（整块填充） | ⚠️ 水印能去掉，但会把框内飘落的绿叶抹淡；且底部若羽化会残留半截字 |
| **`cleanwm --mode selective`（默认，推荐）** | ✅ 只把偏白像素拉向背景色，水印无残留，绿叶/地台/描边完好，背景无色块接缝 |

- 默认框 `--x0 0.86 --y0 0.925 --x1 1 --y1 1`，填充色自动取框上方条带的最亮主色（实测得到 `#C9E3C4` / `#C6E2C9`，都与薄荷绿背景几乎一致）。
- **`--threshold` 调参（2026-11-08 第二张实测）**：默认 `160`。`185` 能去掉主字但会留一层极淡的抗锯齿字影；降到 `160` 后完全干净，深色地台边、绿植、飘叶都不受影响。若右下角恰好有白云、米白石砖等**浅色装饰**，调高到 `190–210` 只抹最白的字（可能留淡影）；背景是大面积渐变时也要调高，否则浅色背景会被拉向填充色。
- 换模型或换背景色后水印位置可能变动：先看一眼成片右下角，必要时用 `--box "x0,y0,x1,y1"` 精确指定，或 `--color "#RRGGBB"` 指定填充色。
- 若背景不是纯色（例如右下角有云朵、招牌），`selective` 比 `fill` 安全得多，`fill` 会整块抹掉装饰——别用 `fill`。
- 拼接环节永远不再裁插画；`cleanwm` 只改水印像素，不改画布尺寸。
