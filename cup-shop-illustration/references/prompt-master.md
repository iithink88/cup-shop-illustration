# 主提示词模板（饮品照片 → 等轴测微缩建筑插画）

> 这份是**直接投喂 ImageGen 的主用版本**。风格条款、负面词、构图约束必须原样保留，只替换 `{{槽位}}`。
> 原文来自用户提供的《饮品照片 → 等轴测微缩建筑插画》提示词，按「图像模型可读」重新分段整理，并补了英文风格锚点。
> **不要**把「代码拼接」「最终交付两份文件」这类工作流指令写进图像提示词——那是 SKILL.md 的职责。

---

## 一、槽位表

| 槽位 | 填什么 | 空缺时怎么办 |
|---|---|---|
| `{{BRAND}}` | 品牌英文名，如 `Grid Coffee`、`CHABaidao` | 从照片 logo 读；读不出写「杯身原有的品牌文字」 |
| `{{DRINK}}` | 饮品英文名，如 `Americano`、`Brown Sugar Boba Milk` | 从标签/用户说明读；读不出就省略副标题，不编造 |
| `{{EXTRA}}` | 联名、产地、庄园、特殊配料，如 `Yunnan · Giupo Estate` | 没有就写「无额外信息」，不要脑补 |
| `{{CANVAS}}` | 竖版 `3:4 portrait` / 横版 `4:3 landscape` / 方形 `1:1 square`（由原图方向决定） | 默认按原图方向 |
| `{{BG}}` | 背景色，如 `soft mint green` | 默认薄荷绿；与品牌色冲突时换成协调的明亮纯色 |
| `{{FEATURES}}` | 与饮品相关的环境元素，如咖啡树枝与红果、珍珠、橙片、茶叶、饼干 | 按识别卡真实填写，不要堆砌 |
| `{{OBSERVATION}}`（可选段） | 一句话写出照片里看到的杯型、主色、logo、杯盖 | 图生图已能看见，写上也无妨，可增强保真 |

## 二、主模板（复制后填槽）

```
请根据我作为 image1 上传的真实饮品照片，将照片中的咖啡／奶茶／饮料改造成一座可爱的品牌主题微缩建筑。必须直接观察参考图进行图生图创作，而不是仅凭文字重新设计一个杯子。

【品牌与饮品信息】
品牌：{{BRAND}}
饮品：{{DRINK}}
补充信息：{{EXTRA}}
照片中可见：{{OBSERVATION}}
优先识别照片中的品牌 Logo、包装、颜色、杯型、文字和饮品特色。无法确认的信息不要自行编造。

【1. 原图参考与轮廓保真 —— 最高优先级】
让图像模型直接观察并理解原图的主体轮廓，不需要预先提取边缘或生成线稿。
重点保留：
- 杯型轮廓：杯身宽高比例、上宽下窄的形态、瓶身或罐身的独特造型；
- 顶部结构：杯盖厚度、杯口轮廓、吸管位置、饮用口、奶盖、奶油等；
- 包装特征：品牌 Logo、主色、标签位置、特殊图案、文字布局；
- 饮品细节：液体颜色、分层、冰块、珍珠、水果、咖啡豆、饼干碎等；
- 独特标识：联名人物、吉祥物、特殊贴纸和装饰。
以原图的杯身轮廓为基础做插画化与建筑化改造，让生成的建筑一眼能看出就是照片里那杯饮料。不要随意替换杯型、改变品牌配色或重新设计包装。
但不要机械复制原照片的拍摄角度，要在保留原始造型的同时做合理的三维空间推演。
核心原则：保留原始饮品的识别特征，重新设计它的建筑功能。

【2. 等轴测微缩建筑设计】
把饮品包装改造成一座充满童趣的品牌主题微缩建筑（Isometric Miniature Diorama）。
采用 Elevated Three-Quarter Isometric View：从建筑斜前方约 45°、向下约 30° 观察，必须能清楚看到建筑顶部、正面、侧面和地台的空间纵深，绝不能用完全正面的产品展示视角。
- 原始杯身作为建筑主体，保留形状与标志性包装特征；
- 杯盖、奶盖、配料自然转化为屋顶、平台、露台或趣味建筑装饰；
- 在杯身上设计圆形/拱形窗户、入口、商店橱窗、阳台；
- 按空间结构增加楼梯、滑梯、观景台、遮阳棚、悬挂招牌等设施；
- 加入可爱的卡通吉祥物与店员小人，让它们在店里喝饮料、玩耍、滑滑梯、向窗外张望；
- 周围搭配盆栽、藤蔓、花朵、草坪等绿植，营造治愈微缩景观；
- 融入与饮品相关的元素：{{FEATURES}}；
- 若有产地、庄园或联名信息，把相关视觉元素自然融入周围环境（如 A 字牌、咖啡果枝）。
所有装饰都围绕品牌与饮品特色展开，不要每次机械复制同一种建筑布局。整座建筑坐落于具有明确等轴测透视的斜向地台上，空间结构合理、层次丰富。

【3. 插画风格 —— 严格遵守】
Bold Outline Isometric Flat Vector Illustration。专业的 2D 等轴测扁平矢量插画，不是 3D 卡通渲染。
- 描边：清晰、均匀、较粗的黑色轮廓线（Thick Consistent Black Outlines）；外轮廓略粗、内部细节略细，转角圆润、线条流畅；
- 色彩：高纯度、干净、明快的纯色色块平涂（Solid Flat Color Fills），大面积平涂，每个物体只用少量相邻色阶表现结构；
- 阴影：只允许少量边界清晰的硬边阴影（Minimal Hard-Edged Flat Shading），不要渐变、真实反射和复杂光照；
- 造型：几何形状简洁圆润，比例可爱，童趣、玩具化，但保持纯二维矢量插画质感；
- 背景：{{BG}} 的纯净背景，可加少量白云、星星、植物等平面装饰；
- 整体品质：精致的商业品牌 IP 插画海报，画面干净、色彩协调、空间关系清晰、细节丰富但不过度复杂。
画面应像专业设计师用 Adobe Illustrator 制作的矢量插画，而不是 Blender / Cinema 4D 渲染的三维场景。
严格避免：3D Rendering, Photorealistic, Plastic Texture, Glossy Highlights, Soft Gradients, Realistic Lighting, Complex Shadows, Metallic Reflections, Painterly Texture, Watercolor, Oil Painting。

【4. 文字与标题排版】
在插画顶部设计完整的品牌英文标题。
- 主标题：{{BRAND}}（大写或首字母大写）
- 副标题：{{DRINK}}
- 补充信息：{{EXTRA}}，用一行更小的英文，放在副标题下方；无信息则省略
文字使用圆润厚实的粗体无衬线字体（Rounded Bold Sans-serif），纯色填充，可配简洁白色描边；不要立体挤压、浮雕、金属、渐变等效果。
主标题突出，副标题清晰但不喧宾夺主。标题距画面顶部至少保留约 8% 安全边距，标题与建筑之间留舒适空白，不要贴着杯盖。

【5. 画面比例与构图】
画布：{{CANVAS}}。只生成一张独立、完整的插画，不要生成左右拼接的对比图、不要画相框或分割线，也不要在画面里放原始照片。
所有建筑、楼梯、滑梯、人物、植物、地台和标题必须完整出现在画面中，主体距左右与底部边缘保留约 6%–8% 安全距离，不截断任何重要结构，不为填满画面而过度放大主体。
不要为了凑比例而拉伸、压扁或裁切内容；生成前就规划好完整构图，而不是完成后再强制裁切。

【执行原则】
原图直接作为视觉参考 → 保留原始杯型和包装轮廓 → 转换为斜上方 3/4 等轴测建筑 → 粗黑描边、纯色平涂的矢量风格 → 输出一张完整独立插画。
最终效果：让人一眼认出原本的那杯饮料，同时惊喜地发现它变成了一座精致、可爱、充满生活气息的微缩小店。
```

## 五、单变量调参法

一次只改一个地方，否则无法判断是哪条生效：

| 症状 | 只改这里 |
|---|---|
| 变成写实 / 3D 渲染 | 在第 3 段开头把 `Bold Outline Isometric Flat Vector Illustration` 提到最前，并追加负面词表 |
| 杯型或配色被换掉 | 提高 `input_fidelity`（medium→high），并在 `{{OBSERVATION}}` 里把主色与 logo 写得更具体 |
| 视角是平的正面照 | 在第 2 段把 `45° / 30° / 顶部·正面·侧面·地台同时可见` 加粗重复一次；必要时降 `input_fidelity` 到 `low` |
| 标题乱码 | 主标题减到 1 个短词、副标题省略；中文一律改用后期 PIL 叠加 |
| 底部地台被切 | 在第 5 段追加 `leave 10% empty margin at the bottom, show the whole base platform` |
| 元素太挤 | 删掉 `{{FEATURES}}` 里 1–2 项，设施列表里去掉滑梯或观景台 |
| 背景太花 | `{{BG}}` 改成单一纯色，删除「白云、星星」等装饰描述 |

## 六、实测记录（2026-11-08 · GridCoffee 绿杯 → Americano）

| 项 | 实测结果 |
|---|---|
| `size=1024x1365` | ✅ 可用，实际返回 `1024x1360`（3:4 竖版） |
| `quality=high` / `input_fidelity=medium` | ✅ 深绿杯身、米白厚杯盖、白色空心方框 logo、GridCoffee 小字全部保留 |
| 等轴测视角 | ✅ 斜上方屋顶露台清晰可见，但略偏正面（右侧立面靠楼梯与侧面窗体现）。想更"斜"就在第 2 段追加 `show the right side wall clearly, rotate the building 45 degrees` |
| 风格 | ✅ 粗黑描边 + 纯色平涂，无 3D 渲染 / 渐变 / 塑料高光 |
| 标题 | ✅ `Grid Coffee / Americano / Yunnan · Giupo Estate` 三行清晰无乱码，中文未生成（按约定全英文） |
| 建筑元素 | ✅ 拱窗、条纹遮阳棚、木楼梯、店员小人、咖啡果枝、A 字牌、石砖地台一应俱全 |
| 水印 | ⚠️ `footnote: ""` 无效，平台强制叠「AI生成 WORKBUDDY」→ 用 `cleanwm` 清除 |
| 拼接 | ✅ 竖版原图走左右拼，输出 `2123x1408` PNG，原图等比缩放无变形 |

**一条经验**：这份模板里最不能省的是第 1 段「轮廓保真」和第 3 段「2D 矢量风格」。实测中杯盖被自然转化成屋顶露台、饮用口变成天窗，说明「保留识别特征 + 重新设计建筑功能」这条心法模型是能听懂的。

## 七、不只是杯子：盒装 / 罐装 / 瓶装怎么改（2026-11-08 第二张实测）

技能虽叫「杯子门店」，但 `image1` 是任意饮品包装都能做。第二张实测对象是**海河纯牛奶利乐砖纸盒**，成品同样合格。改法：

| 原模板措辞 | 换成 |
|---|---|
| 咖啡／奶茶／饮料 | 盒装纯牛奶 / 罐装汽水 / 瓶装果汁 |
| 杯型轮廓、上宽下窄 | 长方体砖形纸盒轮廓、平直棱线、宽高比例 |
| 杯盖厚度、饮用口、吸管 | 青绿色盒顶封边、横向压痕、折角 |
| 杯身 | 白色纸盒盒身 |
| 杯盖变屋顶平台 | 盒顶封边 + 折角变屋顶露台与栏杆，中央开圆形天窗 |
| logo 留在杯身 | 红色 HAI HE 字标与蓝黑徽标留在正面；包装主图（棕色奶牛头像圆徽章）升级成建筑正面最醒目的圆形招牌/彩绘大窗 |

**必须加的一句**：`This is a rectangular aseptic brick carton, NOT a round cup; do NOT turn it into a round coffee cup`，并在负面词里补 `round coffee cup, plastic cup`。否则模型会被技能名里的「杯子」先验带跑，把纸盒画成圆杯。

**中文的新发现**：这次提示词里其实写了「不要生成可辨别中文」以及负面词 `Chinese characters`，模型**仍然**把包装上原有的「纯牛奶」「国有牧场 安心奶源」照搬对了，连 `3.6g / 120mg` 条带都保留——说明图生图对实拍包装文字的保真优先级高于负面约束。所以中文不是绝对禁区：**「照搬包装上已有的中文」成功率较高，「凭空写新中文」仍容易乱码**。默认策略不变（顶部标题用英文）；若用户明确要中文招牌，把这条负面约束去掉、改成「照搬包装原有的中文文字」，出图后人工核对。
